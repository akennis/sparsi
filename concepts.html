Concepts

The ideas behind clawdag-go

Five short guides covering the load-bearing mechanics of the framework — the DAG itself, how to call external tools over MCP, how to wire retrieval and citation validation, how to use AI as a typed recovery path for deterministic ops, and how to plug your own credential routing into the AI client layer.

🧩

DAG engine

Vertices, typed wires, dag field tags, the dagor scheduler, predicate gates, skip-propagation, MapOver fan-out, and Merge. The shape every clawdag workflow starts from.
🛰️

MCP integration

MCPCallOp for one-shot tool calls; MCPScriptOp for multi-call sessions that share server state. Pooled subprocesses, warm replenish, custom MCPArgsFormatter / MCPResponseParser, MCPToolError recovery.
📚

Retrieval & citations

The Retriever interface, RetrieveOp / RetrieveWithFiltersOp, citation allow-list filtering via ValidateCitationsOp, and pluggable embedding providers through EmbeddingClientFactory.
🔧

AI-driven repair

Wrap a deterministic op with WithRepair so a typed *ErrRepairable escalates to an LLM that mutates the input until it parses or satisfies your business rules. Bounded by max_attempts.
🔐

AI credential routing

Implement AIClientFactory to source Anthropic / Gemini clients from Vault, AWS Secrets Manager, workload identity, or per-tenant credentials — without env vars and without changing graph code.
