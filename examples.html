Examples

Twelve real workflows, explained

Each example is a self-contained Go program that demonstrates a distinct DAG pattern. Browse them to see how deterministic ops and AI ops combine in practice — cross-model verification, MapOver fan-out, MCP-driven local and remote tool integrations, retrieval-augmented generation with citation validation, and AI-driven recovery of deterministic ops.

01

Customer Support Ticket Triager

Classifies a free-text ticket with AI, routes it to a category-specific extraction lane, and emits a structured JSON brief. The clearest demonstration of the fan-out / predicate-gate / coalesce pattern.

ModeSelectOp predicate gates parallel lanes CoalesceNStringOp
→
02

Recipe Difficulty Analyzer

Runs three AI extractors in parallel over recipe instructions, then feeds counts and cook time into a deterministic scoring formula to classify difficulty and generate targeted cooking advice.

parallel extractors arithmetic scoring SliceLenOp difficulty lanes
→
03

GitHub README Quality Report

Fetches a repository README (trying main and master branches in parallel), fans out five AI probes concurrently, averages two scores deterministically, and appends an optional test-coverage warning.

parallel HTTP fetches five parallel probes SelectStringOp StringConcatOp
→
04

Weather-Aware Outfit Advisor

Parses live weather numbers with AI, classifies conditions with a multi-label op, computes temperature band and wet/windy flags deterministically, then generates outfit advice with an orthogonal extreme-weather probe.

AIParseNumberOp AIClassifyMultiLabelOp IfFloatGtOp orthogonal probe
→
05

HackerNews Topic Brief

Fans out per-story AI checks across N HN story titles using MapOver, filters and flattens results deterministically, picks a brief style from the dominant category, then summarises in technical, business, or policy format.

MapOver fan-out FilterAndFlattenOp DominantCategoryOp ModeSelectOp
→
06

Faithful Summary

Uses Claude to summarise a source document and Gemini to independently verify that every factual claim is grounded in the source. The clearest demonstration of the cross-model verification pattern — a second, independent model as a quality gate against hallucination.

Claude (summarize) Gemini (verify) FormatFaithfulnessCheckOp AIBoolOp
→
07

Local MCP — Google Search & Per-URL Screenshots

Drives a local playwright-mcp subprocess over stdio: one MCPScriptOp session searches Google and extracts the first three result URLs, then a downstream MapOver fans out three parallel sessions that each open a URL and save a screenshot. Demonstrates session continuity, fan-out across independent sessions, and the warm-replenish session pool.

MCPScriptOp (stdio) MapOver fan-out browser_evaluate MCP session pool
→
08

Remote MCP — Cloudflare Docs Search

Calls the public https://docs.mcp.cloudflare.com/mcp server's search_cloudflare_documentation tool over the streamable HTTP transport — no subprocess, no API keys. A single MCPCallOp vertex shows how a remote MCP endpoint becomes a one-line DAG step.

MCPCallOp (http) remote MCP server streamable HTTP no API key
→
09

Stock Analyzer — zero custom ops

A full live-data workflow built without a single custom operator. Parallel HTTPGetOp from Yahoo Finance, JSONExtractOp for fields, AIParseNumberOp for stringly-typed numerics, deterministic SubFloatOp for the change, AIScoreOp for headline sentiment, and a StringConcatOp chain that assembles the final analysis prompt.

library only HTTPGetOp · JSONExtractOp AIScoreOp multi-step prompt assembly
→
10

RAG (BM25) — local knowledge base with citations

Implements a tiny BM25 retriever over a folder of .txt files, wires RetrieveOp into an XML-wrapped prompt (prompt-injection mitigation), asks the LLM to cite sources, parses the citations, and filters them through ValidateCitationsOp against the retrieved allow-list.

Retriever interface RetrieveOp ValidateCitationsOp grounded answer
→
11

RAG (Gemini embeddings) — vector similarity

The same seven-vertex graph as the BM25 example, with the retriever swapped to in-memory Gemini embeddings + cosine similarity. Demonstrates ResolveEmbeddingClient and the EmbeddingClientFactory abstraction — swap in Voyage, OpenAI, Cohere, or in-house embedders without touching the graph.

EmbeddingClientFactory cosine similarity ValidateCitationsOp vector retrieval
→
12

WithRepair — AI-assisted recovery

A two-stage ticket pipeline that exercises both wire-format paths of library.WithRepair: a JSON parser corrects malformed input (string-target repair); a routing validator round-trips the offending ticket through XML to satisfy a business rule (struct-target repair).

ErrRepairable UnmarshalRepair JSON + XML repair reasoning log
