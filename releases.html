v0.0.0 Initial Preview 2026-05-04

First public release of clawdag-go. Establishes the core DAG execution engine, the deterministic op library, and the typed AI op suite. Everything needed to build deterministic-first AI workflows in Go.

Core engine

dagor execution engine with topological scheduling, parallel branch execution, skip-propagation for predicate gates, and vertex-level error attribution.

Deterministic op library

80+ typed ops covering arithmetic, string manipulation, slice operations, predicates, boolean logic, JSON extraction, HTTP I/O, and select/coalesce patterns.

AI op suite

12 typed AI ops: ModeSelectOp, AIBoolOp, AIScoreOp, AIParseNumberOp, AIExtractStringSliceOp, AIExtractMapOp, AISummarizeOp, AIComputeStringToStringOp, AIBestMatchOp, AIRerankOp, AIClassifyMultiLabelOp, and AIComputeMathOperandsToFloat64Op. All target claude-sonnet-4-6 with up to 3× retry on parse failure.

Examples

Five self-contained example programs demonstrating fan-out/coalesce, parallel AI extractors, MapOver, multi-label classification, and orthogonal probe patterns.
